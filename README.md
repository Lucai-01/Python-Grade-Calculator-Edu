# Student Grade Calculator

Author: Victor Alfred L. Cairel 
Section: IT3r4 - IT314

Description:
This is a simple Python command-line application that prompts the user to enter scores for a specified number of subjects. It validates inputs, calculates the overall average, and outputs the corresponding final letter grade (A, B, C, D, or F).

How to Run:

1. Ensure Python 3.x is installed on your machine.
2. Open your terminal or command prompt in the project directory.
3. Run the application using:

```bash
python grade_calculator.py
